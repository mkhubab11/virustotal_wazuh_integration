# VirusTotal Integration with Wazuh

### Automated Malware Detection through SIEM and Threat Intelligence Integration


## 📌 Project Overview

This project demonstrates the integration of **Wazuh**, an open-source Security Information and Event Management (SIEM) platform, with **VirusTotal**, a cloud-based threat intelligence and malware-scanning service.

The integration uses Wazuh's **File Integrity Monitoring (FIM)** capability to detect newly created or modified files on a Windows endpoint. File hashes generated from these events are checked against VirusTotal's malware database, allowing security analysts to identify potentially malicious files and investigate the resulting alerts through the Wazuh dashboard.

The end-to-end workflow is validated using the **EICAR standard anti-malware test file**, a harmless test file designed to trigger antivirus and malware-detection mechanisms without containing real malicious code.

> **Project Type:** Cybersecurity / SOC Lab
> **Focus:** SIEM Administration, Threat Intelligence, File Integrity Monitoring, and Malware Detection

---

## 🎯 Objectives

* Deploy and configure a Wazuh manager and dashboard.
* Connect and monitor a Windows 11 endpoint using the Wazuh agent.
* Enable File Integrity Monitoring (FIM) on critical user directories.
* Integrate the VirusTotal Public API with Wazuh.
* Automatically check file hashes generated by file-integrity events.
* Validate the detection workflow using the EICAR test file.
* Analyze VirusTotal results and supporting Wazuh alerts.
* Examine file metadata, hashes, detection ratios, and alert classifications.

## ⚙️ Implementation

### 1. Deploy Wazuh and Connect the Windows Agent

Deploy the Wazuh manager and dashboard, then install and register the Wazuh agent on the Windows endpoint.

After successful registration, verify that the endpoint appears as active in the Wazuh dashboard.

The monitored agent used in this project is:

```text
Agent Name: window_agent
Operating System: Windows 11 Pro
```

---

### 2. Configure VirusTotal API Integration

Create or sign in to a VirusTotal account and obtain an API key.

The API key enables the Wazuh manager to perform file-hash reputation checks through VirusTotal.

> **Security Warning:** Never publish your real VirusTotal API key in a GitHub repository. Use an environment-specific configuration or a placeholder in example files.

---

### 3. Configure Wazuh–VirusTotal Integration

Edit the Wazuh manager configuration file:

```bash
sudo nano /var/ossec/etc/ossec.conf
```

Add the VirusTotal integration block inside the existing `<ossec_config>` element:

```xml
<integration>
  <name>virustotal</name>
  <api_key>your_virustotal_api_key</api_key>
  <group>syscheck</group>
  <alert_format>json</alert_format>
</integration>
```

Replace `your_virustotal_api_key` with your actual API key in your local configuration.

**Do not commit the real key to GitHub.**

---

### 4. Configure File Integrity Monitoring

Wazuh Syscheck is configured to monitor the user's **Documents** and **Downloads** directories.

These locations are useful for detecting newly created or modified files, including files introduced through downloads.

The FIM configuration is designed to detect:

* Newly created files
* Modified files
* File-integrity changes
* Associated file hashes and metadata

The exact Windows paths and monitoring settings should match the configuration used in your lab.

---

### 5. Test with the EICAR Test File

The detection workflow is validated using the **EICAR standard anti-malware test file**.

EICAR is a harmless test file recognized by antivirus and security products as a test signature. It does not contain real malicious code.

For safe testing:

1. Use the official EICAR test-file resource.
2. Place the test file in a directory monitored by Wazuh FIM.
3. Allow Wazuh to detect the file-system event.
4. Confirm that the file hash is submitted for VirusTotal reputation analysis.
5. Review the resulting alert in the Wazuh dashboard.

> **Safety Note:** Use the official EICAR test file for validation. Do not download or execute real malware for this lab exercise.

## 🔄 Detection Workflow

```text
1. File created or modified
          ↓
2. Wazuh FIM detects the file event
          ↓
3. File hash is collected
          ↓
4. Wazuh sends the hash to VirusTotal
          ↓
5. VirusTotal returns reputation results
          ↓
6. Wazuh generates an alert
          ↓
7. Analyst investigates the alert
```

## 📊 Results and Log Analysis

When the EICAR test file was placed in a monitored directory, Wazuh detected the file-system change and forwarded the file hash to VirusTotal.

The resulting alerts provided information such as:

* File name
* File path
* File hash values
* VirusTotal detection ratio
* VirusTotal permalink
* File-integrity event type
* Alert rule classification
* MITRE ATT&CK mapping
* Compliance-related tags

## 🔐 Security Considerations

* Never commit API keys, passwords, or private credentials.
* Replace sensitive values with placeholders in configuration examples.
* Do not upload real malware samples to a public repository.
* Be aware that submitting file hashes to an external threat-intelligence service shares those hashes with that service.
* Use test files such as EICAR for safe validation.
* Review API usage limits and the terms of the VirusTotal service before deploying integrations in production.

## ⚠️ Scope and Limitations

This project focuses on **file-hash reputation checks through the VirusTotal Public API**.

It does not cover:

* Network-based threat intelligence
* Automated endpoint response
* Malware removal or remediation
* Full malware reverse engineering
* Real malware execution
* Automated incident containment

The results represent the documented lab environment and its configuration.
